# Maven and Spring Framework Learning

This branch documents my learning journey in **Apache Maven** and **Spring Framework**, two essential tools for modern Java development. Maven is used for build automation and dependency management, while Spring provides comprehensive infrastructure support for building Java applications, especially for enterprise-level software.

## Topics Covered

### 1. Apache Maven
- **Project Structure**: Understanding the Maven directory layout.
- **POM File**: Introduction to the `pom.xml` configuration file for managing dependencies and plugins.
- **Dependency Management**: How to add and manage external libraries.
- **Build Lifecycle**: Key phases like `validate`, `compile`, `test`, `package`, and `install`.
- **Plugins**: Using plugins to extend project functionality (e.g., compiler and Surefire plugins).

### 2. Spring Framework Basics
- **Dependency Injection (DI)**: Concept of Inversion of Control (IoC) and how Spring handles DI.
- **Spring Beans**: Creating, managing, and configuring beans.
- **Application Context**: Using `ApplicationContext` to manage beans and configurations.
- **Spring Annotations**: Introduction to annotations like `@Component`, `@Autowired`, `@Configuration`, and their usage.
- **Spring Boot (Upcoming)**: A look forward to using Spring Boot for simplifying Spring application setup.

## Key Concepts

### Maven Key Concepts
1. **POM (Project Object Model)**: Core configuration file (`pom.xml`) for dependencies and build settings.
2. **Dependencies**: Managing external libraries and ensuring compatibility.
3. **Build Lifecycle**: Steps like compile, test, and package to streamline development.
4. **Repositories**: Storing and retrieving dependencies from local and remote repositories.

### Spring Key Concepts
1. **Dependency Injection (DI)**: Loosely coupling components by managing dependencies through the Spring container.
2. **Inversion of Control (IoC)**: Delegating control to the Spring IoC container.
3. **Spring Beans**: Defining and managing components in a Spring application.
4. **Annotations**: Simplifying configuration with `@Component`, `@Service`, `@Repository`, etc.
